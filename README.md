# Awesome-Enterprise-Wiki

## Top Enterprise Wiki Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Team Knowledge Bases, Internal Documentation, Collaborative Wikis, Structured Knowledge Management & Self-Hosted Alternatives*

**Last updated: August 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Enterprise Wikis** and internal knowledge bases. These tools help organizations capture, organize, search, and share institutional knowledge through structured pages, spaces, and collaborative editing.



**Examples** include Confluence, Notion, Slab, Nuclino, BookStack, Outline, Wiki.js, Tettra, Guru, and Document360 (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project. Several of the listed tools (BookStack, Outline, Wiki.js) are themselves open-source or have strong self-hosted editions, and many additional mature alternatives exist for teams that want full data ownership.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[BookStack](https://github.com/BookStackApp/BookStack)**  

  Popular open-source wiki with an intuitive books → chapters → pages hierarchy, WYSIWYG + Markdown editing, and solid authentication options.



- **[Wiki.js](https://github.com/requarks/wiki)**  

  Modern, highly configurable open-source wiki built on Node.js with multiple editors, Git storage, advanced permissions, and excellent search.



- **[Outline](https://github.com/outline/outline)**  

  Beautiful open-source (Business Source License) knowledge base with real-time collaboration, collections, and a polished writing experience.



- **[Docmost](https://github.com/docmost/docmost)**  

  Open-source, self-hosted wiki platform positioned as a modern alternative to Notion and Confluence, with real-time collaboration and enterprise features.



- **[XWiki](https://github.com/xwiki)**  

  Mature, fully open-source enterprise wiki platform with fine-grained permissions, structured data, extensions, and strong governance capabilities.



- **[MediaWiki](https://github.com/wikimedia/mediawiki)**  

  The battle-tested open-source engine that powers Wikipedia; highly extensible and suitable for large-scale knowledge bases (often via distributions like BlueSpice).



- **[DokuWiki](https://github.com/dokuwiki/dokuwiki)**  

  Lightweight, file-based open-source wiki that requires no database and is easy to deploy and maintain.



- **[BlueSpice](https://github.com/hallowelt)**  

  Enterprise-oriented open-source distribution and extension set built on MediaWiki, adding features needed for corporate knowledge management.



- **[Foswiki / TWiki descendants](https://github.com/)**  

  Classic structured wiki systems still maintained in open-source form for specific enterprise use cases.



- **[Trilium Notes and hierarchical knowledge tools](https://github.com/)**  

  Powerful open-source personal/team knowledge bases that can scale into internal documentation use cases.



### Additional Strong Open-Source Options

- Raneto, GitBook (open parts), and other Markdown-centric documentation platforms.

- Logseq, AppFlowy, and related tools that support collaborative knowledge graphs.

- OpenKM and document-management systems with wiki-like features.

- Static-site generators (MkDocs, Docusaurus, Hugo) combined with Git workflows for documentation-as-code.

- Custom solutions built on Markdown + Git + search (Meilisearch, Typesense) for lightweight internal wikis.



**Frameworks for building custom systems**: Deploy **BookStack** or **Wiki.js** for structured team documentation, **Outline** or **Docmost** for a modern collaborative feel, or **XWiki/MediaWiki** when you need enterprise-grade permissions and extensibility. Store content in Git where possible, integrate SSO (SAML/OIDC/LDAP), and layer open search engines for discoverability. Many teams combine a self-hosted wiki with static documentation sites for public or developer-facing content.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.

- Knowledge bases contain sensitive internal information. Self-hosted open-source solutions give excellent control and cost advantages but require proper security hardening, backups, access control, and ongoing maintenance.

- Evaluate search quality, permission models, migration paths, and long-term project health before committing to any platform.
